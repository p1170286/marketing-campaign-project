# Marketing Campaign Performance Analysis and Prediction

This project analyzes marketing campaign data from Nykaa, Purplle, and Tira. It includes data cleaning, exploratory analysis, machine learning models, and a Streamlit app for campaign predictions.

## Features

- Combines campaign data from three brands
- Cleans missing values and analyzes campaign performance
- Predicts campaign revenue
- Predicts whether a campaign is likely to be profitable
- Provides an interactive Streamlit app

## Models

- Revenue: Random Forest Regressor
- Profit/Loss: Random Forest Classifier
